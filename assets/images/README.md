# 📸 Carpeta de Imágenes - Boda Fredy & Yanet

En esta carpeta puedes colocar y reemplazar las fotografías para la invitación de boda.

## Archivos y dimensiones recomendadas:

| Nombre de archivo | Uso en la web | Dimensión recomendada | Formato |
| :--- | :--- | :--- | :--- |
| `hero-novios.jpg` | Foto principal en el marco superior | 800 x 1000 px (proporción 4:5 vertical) | JPG o WebP |
| `mapa-bg.jpg` | Fondo de la tarjeta de ubicación | 1200 x 600 px (horizontal) | JPG o WebP |
| `galeria-1.jpg` | Foto de historia 1 ("La Alianza Sagrada") | 800 x 800 px (cuadrada 1:1) | JPG o WebP |
| `galeria-2.jpg` | Foto de historia 2 ("Caminando Hacia el Futuro") | 800 x 800 px (cuadrada 1:1) | JPG o WebP |

> **Nota:** Si quieres usar tus propias fotos con otros nombres, simplemente edita el atributo `src="..."` de cada etiqueta `<img>` en `index.html`.
